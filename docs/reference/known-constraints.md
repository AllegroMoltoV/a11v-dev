# 既知の制約

運用で前提になる制約と、現時点で確認していない事項を記載します。

## 制約

| 項目 | 内容 |
| --- | --- |
| ゾーン設定への依存 | 目標のうち、実行される JavaScript 0 件、圧縮、304 は、[ゾーン設定](zone-settings.md) に依存する。設定が変わると崩れる |
| DNS の書き込み | `wrangler` のログインで付与される権限には、DNS レコードの書き込みがない。DNS レコードは、Cloudflare のダッシュボードで作成する |
| 外部リンクの検査 | `npm run check:links` は、403・405・429・5xx の応答を不確定として扱い、失敗にしない。MCP の窓口 (`/mcp`) は、GET に 405 を返す |
| モバイルの TBT | Lighthouse のモバイルで、TBT が 0 ms から 32 ms になるページがある。実行される JavaScript は 0 件であり、性能スコアは 100 である |
| 窓口のメールアドレス | リポジトリに含めない。ビルド時に、環境変数 `A11V_CONTACT` か、`site/data/contact.local.txt` から読む。指定がないと、ビルドは失敗する |

## 未確認の事項

| 項目 | 内容 |
| --- | --- |
| 実回線での測定 | Lighthouse のモバイルの模擬の低速回線で測定した。実回線では測定していない |
| 実機 | 実機のスマートフォンでの表示は確認していない |
| 支援技術 | スクリーンリーダーでの読み上げは確認していない |
| 検索エンジン | 登録状況と、検索結果での表示は確認していない |
| JavaScript Detections | Cloudflare の Security > Bots の設定。現在の状態を記録していない。公開中の HTML に `<script` と `/cdn-cgi/` がないことは確認している |
