# 用語集

このリポジトリの文書で使う用語を定義します。同じ対象には、ここで定義した名前を使います。

## 人と役割

| 名前 | 定義 |
| --- | --- |
| 依頼者 | AllegroMoltoV。コーディングエージェントに作業を依頼し、判断と承認を行う人 |
| 利用者 | a11v.dev を閲覧する人。依頼者を含まない |

## 用語

| 用語 | 定義 | 別名 |
| --- | --- | --- |
| a11v lab | AllegroMoltoV が運営する、ソフトウェアの個人の研究開発ブランド | |
| 問い | a11v lab が探求するソフトウェアの課題。6 つある | question |
| 成果 | 問いに対して作ったソフトウェアや文書 | プロダクト |
| 詳細ページ | 成果 1 件ごとの、`/<slug>` のページ。10 件ある | |
| 1 行項目 | 一覧にだけ載せ、詳細ページを持たない成果 | |
| 公開用ビルド | 検索エンジンへの登録を許すビルド。`npm run build:release` で生成する | |
| 非公開ビルド | 全ページに noindex を付けるビルド。`npm run build` で生成する | |
| 配備 | `dist/` を Cloudflare Workers の静的アセットとして公開すること。`npm run release` で行う | デプロイ |
| ゾーン | Cloudflare で管理する a11v.dev のドメイン単位の設定 | |
| 本体 | HTTP 応答のうち、ヘッダーを除いた HTML。転送量は圧縮後のバイト数で示す | |
| 弱い ETag | `W/"…"` の形式の ETag。内容が意味的に同じなら一致する | |
| 304 | `If-None-Match` による再訪問で、本体を再転送しない応答 | |
